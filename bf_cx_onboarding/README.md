# bf_cx_onboarding : panneau de mise en route

S'auto-installe quand `bf_cx` et `bf_onboarding_base` sont installés.
Ajoute le panneau de mise en route du module Expérience client en
quatre étapes : créer un programme, configurer la cadence, lancer une
première vague, configurer l'équipe Plaintes. Chaque étape se coche
d'elle-même quand l'action correspondante est posée (création d'un
programme, vague envoyée, cadence ajustée, première plainte
consignée). Aucun envoi au client.
