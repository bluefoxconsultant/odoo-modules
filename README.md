# Blue Fox - Odoo 18 CE Modules

Custom Odoo 18 Community Edition modules developed by [Blue Fox Inc.](https://bluefoxconsultant.com)

## Modules

| Directory | Name | Version | Description |
|---|---|---|---|
| `audit_ti` | Audit TI - Loi 25 | 18.0.1.16.0 | Gestion des audits de sécurité informatique pour la conformité Loi 25 |
| `bf_gamification` | Fox Quest | 18.0.2.0.0 | Système de gamification avec XP, niveaux, badges et récompenses |
| `bf_hour_bank` | Banque d'heures | 18.0.1.6.0 | Suivi automatisé des banques d'heures client |
| `bf_mail_import` | BF Import courriel (.eml) | 18.0.1.1.0 | Importer des fichiers .eml dans le chatter Odoo |
| `bf_task_unblock_notify` | BF Notification de déblocage de tâche | 18.0.1.6.1 | Notifie les assignés quand leur tâche est débloquée |

| `bf_universal_search` | BF Recherche universelle | 18.0.1.3.0 | Recherche transversale dans tous les modules via la palette de commandes |
| `bf_webmail` | Courriel Blue Fox | 18.0.1.1.0 | Accès au courriel SnappyMail depuis la barre Odoo |
| `calendar_nextcloud_sync` | Calendar Nextcloud Sync | 18.0.1.20.0 | Bidirectional calendar synchronization between Odoo and Nextcloud via n8n |

## Installation

Add this repository to your Odoo `addons_path`:

```conf
addons_path = /path/to/odoo/addons,/path/to/odoo-modules
```

Then install individual modules from the Odoo Apps menu.
